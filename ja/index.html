競合の処理方法は 2 つ

常に上書き

コピー元のバージョンがコピー先を置き換えます。 シンプルで予測可能 — コピー元が正しいと分かっているときに。

MD5 チェック — ファイルを失わない

内容が同一（MD5 で検証）のファイルはスキップ。同名でも内容が 異なるファイルは name-2.ext、name-3.ext… として並べてコピーされます。このモードではコピー先のデータが 失われることはなく、同じマージを再実行しても重複は発生しません。

現実のフォルダのために

🔍 ドライラン

ファイルに触れる前に、すべてのコピー・スキップ・名前変更を プレビュー — 使用されるファイル名まで正確に。

🗂 数百万ファイル

ライブスキャンカウンター、バッチ UI 更新、どの段階でも キャンセル可能。ボリュームのメタデータフォルダは自動スキップ。

📋 絞り込めるログ

すべての操作をファイル単位で記録。コピー済み・上書き済み・ スキップ済み・名前変更済み・失敗で絞り込み、異なる 1 ファイルを すぐ発見。

🌐 3 つの言語

English、繁體中文、日本語 — 設定（⌘,）でいつでも切り替え。

🧪 検証済みエンジン

マージエンジンは UI に依存しない純粋な Swift。競合、再実行、 特殊なファイル名を網羅するテスト付き。

🍎 ネイティブ

SwiftUI、Apple Silicon ネイティブ、依存関係なし。 小さな .app ひとつ。
