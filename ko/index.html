충돌 처리 방식 두 가지

항상 덮어쓰기

원본 버전이 대상 버전을 대체합니다. 원본이 정답임을 알고 있을 때 — 단순하고 예측 가능합니다.

MD5 검사 — 파일을 잃지 않기

내용이 동일한(MD5로 검증) 파일은 건너뜁니다. 이름이 같지만 내용이 다른 파일은 name-2.ext, name-3.ext… 형태로 나란히 복사됩니다. 이 모드에서는 대상 폴더의 데이터가 손실되지 않으며, 같은 병합을 다시 실행해도 중복이 생기지 않습니다.

실제 폴더를 위한 설계

🪄 경로 모디파이어

원본과 대상 사이에 템플릿을 — ${YEAR}/${MONTH}/${exif:camera-brand|Unknown}/… — 사진이 촬영 날짜와 카메라별로 지나가면서 자동 정리됩니다. 토큰별 폴백은 당신의 선택. 설계 노트 읽기 →

🔍 드라이 런

파일을 건드리기 전에 모든 복사·건너뛰기·이름 변경을 미리 보기 — 사용될 파일 이름까지 정확하게.

🗂 수백만 개의 파일

실시간 스캔 카운터, 일괄 UI 업데이트, 어느 단계에서든 취소 가능. 볼륨 메타데이터 폴더는 자동으로 건너뜁니다.

📋 필터링 가능한 로그

모든 동작이 파일별로 기록됩니다. 복사됨·덮어씀·건너뜀·이름 변경됨·실패로 필터링하여 다른 파일 하나를 바로 찾아내세요.

🌐 세 가지 언어

English, 繁體中文, 日本語 — 설정(⌘,)에서 언제든지 전환.

⚡️ 즉시 복사

같은 APFS 볼륨 내 복사는 카피온라이트 클론으로 — 즉시 완료되며 추가 디스크 공간도 차지하지 않습니다.

⚖️ 빠르게 또는 철저하게

빠른 모드는 크기＋수정 날짜로 비교하고 판별이 안 될 때만 MD5를 사용합니다. 철저 모드는 모든 파일을 해시 검증 — 아카이브급 확인은 당신의 선택.

🧪 검증된 엔진

병합 엔진은 UI가 없는 순수 Swift로, 충돌·재실행·특이한 파일 이름을 포괄하는 테스트를 갖추고 있습니다.

🍎 네이티브

SwiftUI, Apple Silicon 네이티브, 의존성 없음. 작은 .app 하나.

자주 묻는 질문

Mergic이 파일을 삭제하거나 덮어쓸 수 있나요?

MD5 모드에서는 아닙니다 — 대상 폴더의 파일은 절대 삭제되거나 교체되지 않습니다. 내용이 다른 동명 파일은 name-2.ext로 나란히 복사되어 두 버전 모두 보존됩니다. 명시적으로 “항상 덮어쓰기” 모드를 선택한 경우에만 교체되며, 드라이 런으로 미리 확인할 수 있습니다.

드라이 런은 정확히 무엇을 하나요?

스캔, 비교, 충돌 처리까지 병합의 전 과정을 실행하지만 아무것도 쓰지 않습니다. 사용될 정확한 파일 이름이 담긴 전체 로그를 볼 수 있어 놀랄 일이 없습니다.

빠르게 vs 철저하게 — 무엇을 써야 하나요?

빠른 모드는 크기＋수정 날짜로 비교하고 판별이 안 될 때만 MD5를 사용합니다. 기본 선택이며 매우 빠릅니다. 타임스탬프를 신뢰할 수 없거나(카메라 카드, 복원된 백업) 대체 불가능한 데이터를 검증할 때는 철저 모드를 — 모든 파일을 해시 검증하여 무음 손상까지 잡아냅니다.

이름이 같지만 내용이 다른 파일은 어떻게 되나요?

원본 버전이 name-2.ext(다음은 name-3.ext…)로 대상 파일 옆에 복사됩니다. 같은 병합을 다시 실행해도 중복이 쌓이지 않습니다 — 기존 변형 파일은 먼저 내용을 확인합니다.

다른 드라이브 간에도 작동하나요?

네. 같은 APFS 볼륨 내 병합은 카피온라이트 클론을 사용해 즉시 완료되며 공간을 차지하지 않습니다. 드라이브 간에는 일반 복사를 수행합니다.

Mergic이 데이터를 어디론가 전송하나요?

아니요. 샌드박스에서 실행되며 네트워크 기능도 분석 기능도 없고, 선택한 폴더에만 접근합니다.
