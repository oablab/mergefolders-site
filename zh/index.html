兩種衝突處理方式

一律覆寫

來源版本會取代目的地版本。簡單且可預期 — 當你確定來源才是正確版本時。

MD5 檢查 — 絕不遺失檔案

內容相同（經 MD5 驗證）的檔案會被略過。同名但內容不同的檔案， 會以 name-2.ext、name-3.ext… 的形式複製到旁邊。此模式下目的地永遠不會遺失資料， 重複執行同一次合併也不會產生重複檔案。

為真實世界的資料夾而生

🔍 模擬執行

在動到任何檔案之前，預覽每一個複製、略過與重新命名 — 連將使用的檔名都一清二楚。

🗂 數百萬檔案

即時掃描計數、批次 UI 更新、任何階段都能取消。 自動略過磁碟區中繼資料夾。

📋 可篩選記錄

每個檔案的動作都有記錄。可依已複製、已覆寫、已略過、 已重新命名或失敗篩選，快速找出那個不同的檔案。

🌐 三種語言

English、繁體中文、日本語 — 隨時用 ⌘, 在設定中切換。

🧪 經過驗證的引擎

合併引擎是純粹、無 UI 的 Swift， 附完整測試，涵蓋衝突、重複執行與各種特殊檔名。

🍎 原生

SwiftUI、Apple Silicon 原生、零相依套件。 一個輕巧的 .app。
